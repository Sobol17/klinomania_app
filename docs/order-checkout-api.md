# API оформления заявки на уборку

Документ задаёт контракт между мобильным приложением и backend. Базовый URL: `/api/v1`. Формат обмена — JSON в UTF-8; все имена полей — `snake_case`.

## Сценарий

1. Клиент выбирает услугу и дополнительные опции.
2. На экране оформления выбирает адрес из подсказки, указывает детали входа, дату и время.
3. Приложение одним запросом создаёт заявку.
4. Backend проверяет конфигурацию, сам рассчитывает итоговую цену, создаёт ID заявки и сохраняет её.

Предварительный расчёт (`quote`), `quote_id` и отдельный API для расчёта не используются. Площадь помещения также не участвует в API и расчёте цены. Клиент не передаёт цену и не формирует ID заявки.

## Общие требования

- Метод требует `Authorization: Bearer <access_token>` и доступен только роли `client`.
- Итоговая цена рассчитывается только на backend и возвращается в целых рублях (`integer`), валюта v1 — `RUB`.
- `scheduled_at` передаётся в ISO 8601 со смещением часового пояса, например `2026-07-20T11:00:00+08:00`.
- Пустые необязательные строки backend нормализует в `null`.

## Создание заявки

### `POST /client/orders`

Создаёт заявку на уборку. Идентификатор заявки генерируется backend и базой данных.

### Заголовки

| Заголовок | Обяз. | Описание |
| --- | --- | --- |
| `Authorization` | да | `Bearer <access_token>`. |
| `Idempotency-Key` | да | UUID v4, сгенерированный приложением для одной попытки оформления. Защищает от двойного создания при повторной отправке. |

### Тело запроса

| Поле | Тип | Обяз. | Описание и ограничения |
| --- | --- | --- | --- |
| `service_id` | `string` | да | Идентификатор активной услуги из каталога. |
| `room_option_id` | `string \| null` | нет | ID выбранного варианта количества комнат; передаётся, если группа доступна для услуги. |
| `cleaning_option_id` | `string \| null` | нет | ID выбранного основного типа уборки. |
| `extra_option_ids` | `string[]` | да | ID дополнительных работ. Если дополнений нет — `[]`; повторы не допускаются. |
| `address` | `object` | да | Адрес и сведения для доступа. Поля приведены ниже. |
| `comment` | `string \| null` | нет | Инструкция для исполнителя. Рекомендуемый максимум — 500 символов. |
| `scheduled_at` | `string(date-time)` | да | Желаемые дата и время начала уборки. Не ранее текущего момента и не позднее 365 дней. |
| `payment_method` | `string \| null` | нет | Способ оплаты. Текущее приложение передаёт `null`; поле зарезервировано для интеграции оплаты. |

#### Объект `address`

| Поле | Тип | Обяз. | Описание и ограничения |
| --- | --- | --- | --- |
| `full_address` | `string` | да | Полный адрес, выбранный из подсказки. Не менее трёх символов после `trim`. |
| `entrance` | `string \| null` | нет | Номер подъезда. |
| `floor` | `string \| null` | нет | Этаж; строковый формат допускает «цокольный» или «2А». |
| `apartment` | `string \| null` | нет | Номер квартиры, офиса или помещения. |
| `intercom` | `string \| null` | нет | Код домофона. |

Пример запроса:

```json
{
  "service_id": "standard",
  "room_option_id": "room-2",
  "cleaning_option_id": "standard-cleaning",
  "extra_option_ids": ["fridge-inside", "windows-room-2"],
  "address": {
    "full_address": "г. Иркутск, ул. Ленина, д. 10",
    "entrance": "1",
    "floor": "4",
    "apartment": "42",
    "intercom": "42"
  },
  "comment": "Позвонить за 15 минут",
  "scheduled_at": "2026-07-20T11:00:00+08:00",
  "payment_method": null
}
```

### Успешный ответ `201 Created`

```json
{
  "data": {
    "id": "01J2QM1R7H7YV9JH1KACD6ZK3R",
    "status": "processing",
    "status_label": "В обработке",
    "scheduled_at": "2026-07-20T11:00:00+08:00",
    "total_price": 9100,
    "currency": "RUB",
    "service": {
      "id": "standard",
      "title": "Базовый минимум"
    },
    "created_at": "2026-07-15T09:01:30Z"
  }
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `data.id` | `string` | Уникальный ID созданной заявки; генерируется backend/БД. |
| `data.status` | `string` | Машинный статус; при создании — `processing`. |
| `data.status_label` | `string` | Отображаемое название статуса. |
| `data.scheduled_at` | `string(date-time)` | Подтверждённые дата и время начала. |
| `data.total_price` | `integer` | Зафиксированная итоговая цена, рассчитанная сервером, в рублях. |
| `data.currency` | `string` | Код валюты ISO 4217, в v1 — `RUB`. |
| `data.service.id` | `string` | ID выбранной услуги. |
| `data.service.title` | `string` | Название услуги на момент оформления. |
| `data.created_at` | `string(date-time)` | Время создания заявки. |

### Идемпотентность

Backend хранит `Idempotency-Key` и хеш тела запроса минимум 24 часа в пределах пользователя. Повторный идентичный запрос возвращает уже созданную заявку (`200 OK` либо исходный `201 Created`). Если тело с тем же ключом отличается, backend отвечает `409 idempotency_key_conflict`.

## Обязательные серверные проверки

В одной транзакции backend должен:

1. Проверить, что услуга существует и активна.
2. Проверить принадлежность опций услуге, отсутствие дублей и совместимость опций между собой.
3. Проверить `scheduled_at`, доступность временного слота и зону обслуживания по `full_address`.
4. Рассчитать итоговую цену по актуальному серверному тарифу. Цена, ID заявки и служебные статусы формируются только на сервере.
5. Сохранить в заявке неизменяемые снимки услуги, выбранных работ, цены и адреса, чтобы изменения каталога и тарифа не меняли историю.

## Ошибки

Ошибки возвращаются в едином формате:

```json
{
  "message": "The selected time is unavailable.",
  "code": "slot_unavailable",
  "errors": {
    "scheduled_at": ["Выбранное время уже занято."]
  }
}
```

| HTTP | `code` | Когда возвращать |
| --- | --- | --- |
| `401` | `unauthenticated` | Нет, истёк или некорректен токен. |
| `403` | `forbidden` | Роль пользователя не `client`. |
| `404` | `service_not_found` | Услуга не найдена или недоступна. |
| `409` | `idempotency_key_conflict` | Тело отличается от ранее полученного с тем же ключом. |
| `422` | `validation_error`, `outside_service_area`, `slot_unavailable` | Ошибка полей, адрес вне зоны или слот занят. В `errors` указывать проблемные поля. |
| `429` | `rate_limited` | Превышен лимит запросов. |
