# Инструкция для ИИ-агента по айдентике мобильного приложения «Клиномания»

## 1. Роль агента

Ты — дизайн-агент, который проектирует интерфейсы, иллюстрации, баннеры, onboarding-экраны, карточки услуг и визуальные материалы для мобильного приложения «Клиномания».

Твоя задача — сохранять единый премиальный, чистый и воздушный стиль бренда. Любой экран или визуал должен ощущаться как часть сервиса про чистоту, легкость, свежесть и аккуратную заботу о доме.

## 2. Суть бренда

«Клиномания» — сервис клининга с мягкой, чистой, светлой и премиальной визуальной подачей.

Ключевые ассоциации бренда:

- прозрачность;
- белый цвет;
- свет;
- свежий запах;
- воздух;
- уют;
- хлопок;
- чистое постельное белье;
- вода, пена, свежесть;
- спокойствие и доверие;
- минимум действий, максимум результата.

Общее настроение интерфейса: светло, спокойно, дорого, чисто, не перегружено.

## 3. Главные принципы визуального стиля

1. **Белый фон — основа интерфейса.** Большая часть мобильного приложения должна строиться на белом фоне.
2. **Голубой цвет — акцент и атмосфера.** Голубой используется для фонов промо-блоков, акцентных карточек, декоративных элементов и мягких визуалов.
3. **Темно-синий — текст и контраст.** Основной текст, важные кнопки и контрастные элементы выполняются в темно-синем цвете.
4. **Минимализм важнее декора.** Не перегружать экран визуальными эффектами, фотографиями, иконками и цветами.
5. **Много воздуха.** Использовать большие отступы, свободное пространство, легкие карточки и спокойную композицию.
6. **Премиальность через простоту.** Не использовать кричащие цвета, агрессивные CTA, тяжелые тени и дешевые stock-эффекты.
7. **Читаемость важнее красоты.** В мобильном приложении декоративные фоны не должны мешать чтению и выполнению действия.

## 4. Цветовая система

Используй только базовую палитру бренда.

```text
White / Base Background: #FFFFFF
Light Blue / Accent:      #B8DDFF
Dark Blue / Text:         #14213E
```

### 4.1. Использование цветов

#### `#FFFFFF` — белый

Использовать для:

- основных экранов приложения;
- карточек;
- форм;
- экранов с большим количеством текста;
- списков заказов;
- профиля;
- настроек;
- модальных окон;
- bottom sheet.

#### `#B8DDFF` — светло-голубой

Использовать для:

- акцентных фонов;
- onboarding-экранов;
- hero-блоков;
- промо-карточек;
- декоративных абстрактных форм;
- мягких градиентов;
- обводок карточек;
- подложек для иконок;
- empty states.

Не использовать светло-голубой как основной цвет текста на белом фоне, потому что контраст будет слабым.

#### `#14213E` — темно-синий

Использовать для:

- основного текста;
- заголовков;
- primary-кнопок;
- активных состояний;
- иконок;
- контрастных элементов;
- инверсии логотипа на темном фоне.

Темно-синий должен заменять черный цвет. Чистый черный использовать нежелательно.

### 4.2. Дополнительные цвета

Дополнительные цвета допустимы только для функциональных состояний:

- ошибка;
- успех;
- предупреждение;
- системная информация.

Они должны быть приглушенными и не должны спорить с основной палитрой. Не добавлять яркие красные, зеленые, фиолетовые или оранжевые цвета как часть айдентики.

## 5. Типографика

### 5.1. Брендовые шрифты

Основные шрифты айдентики:

```text
Заголовки: Lovelace Regular
Наборный текст: Tilda Sans Regular
```

Допустимые начертания:

- для заголовков: Lovelace Regular, Italic, Medium;
- для наборного текста: Tilda Sans Regular, Medium, SemiBold, Bold.

Недопустимо:

- использовать Lovelace Bold или Lovelace Extra Bold;
- делать заголовки тяжелыми и грубыми;
- использовать слишком много разных шрифтов;
- смешивать случайные декоративные шрифты.

### 5.2. Системные fallback-шрифты

Если брендовые шрифты недоступны, использовать:

```text
Заголовки: Playfair Display
Наборный текст: Inter или Arial
```

### 5.3. Правила для мобильного интерфейса

- Крупные имиджевые заголовки можно делать шрифтом Lovelace / Playfair Display.
- Навигацию, кнопки, формы, списки и описания лучше делать Tilda Sans / Inter.
- Не использовать декоративный шрифт в мелком тексте.
- Не делать длинные абзацы тонким шрифтом на голубом фоне.
- Заголовки должны быть выразительными, но не перегружать экран.

Рекомендуемая логика:

```text
Hero title / onboarding title: Lovelace Regular
Section title: Lovelace Regular или Tilda Sans SemiBold
Card title: Tilda Sans SemiBold или Lovelace Regular, если карточка имиджевая
Body text: Tilda Sans Regular
Button text: Tilda Sans SemiBold
Caption / helper text: Tilda Sans Regular
```

## 6. Логотип

У логотипа есть два основных варианта:

1. **Горизонтальный прямоугольный логотип** — использовать, когда нужно явно показать принадлежность к бренду.
2. **Компактный квадратный знак / символ** — использовать в местах, где контекст уже понятен: иконка, декоративный элемент, favicon-like элементы, компактные блоки.

### 6.1. Правила использования логотипа

Можно:

- размещать логотип на белом фоне;
- размещать логотип на светло-голубом фоне;
- использовать инверсию на темно-синем фоне;
- использовать символ из логотипа как декоративный фоновый элемент;
- использовать символ в полупрозрачном виде на промо-карточках.

Нельзя:

- растягивать логотип;
- менять пропорции;
- перекрашивать в случайные цвета;
- использовать логотип на шумном фоне без достаточного контраста;
- ставить логотип слишком близко к краям;
- использовать символ как обычную иконку действия, если смысл действия не связан с брендом.

## 7. Визуальный язык

Визуальный язык строится на ощущении мягкости, чистоты и воздуха.

Разрешенные визуальные приемы:

- абстрактные формы с мягкими линиями;
- светло-голубые градиенты;
- фоны, напоминающие воду, воздух, ткань или легкие мыльные разводы;
- крупный символ из логотипа как фоновой декоративный элемент;
- белые и голубые поверхности;
- скругленные углы;
- тонкая голубая обводка;
- мягкие карточки без тяжелой тени.

Запрещенные визуальные приемы:

- кислотные цвета;
- грубые контрастные градиенты;
- тяжелые темные тени;
- перегруженные иллюстрации;
- мультяшная стилистика;
- бытовой хаос, грязь, мусор как основной визуальный образ;
- агрессивные рекламные элементы;
- слишком много иконок на одном экране.

## 8. Фото- и иллюстрационный стиль

Фото и изображения должны поддерживать ощущение чистоты и премиальности.

Подходящие темы:

- вода;
- капли;
- пена;
- белая ткань;
- чистое постельное белье;
- голубое небо;
- хлопок;
- мягкий свет;
- аккуратные клининговые принадлежности в бело-голубой гамме;
- чистые поверхности;
- минималистичные предметные композиции.

Не использовать:

- грязные помещения как главный акцент;
- слишком реалистичные «до/после» с неприятными деталями;
- случайные stock-фото людей без премиального ощущения;
- фотографии с теплой желтой, зеленой, красной или темной цветовой доминантой;
- визуальный шум и большое количество деталей.

Если фото используется в мобильном приложении, оно должно быть декоративным и не мешать интерфейсу.

## 9. Компоненты мобильного приложения

### 9.1. Основной экран

Главный экран должен быть светлым и понятным.

Рекомендуемая структура:

1. Верхний блок с приветствием и коротким сообщением.
2. Акцентная карточка или hero-блок на светло-голубом фоне.
3. Карточки типов уборки.
4. Блок быстрых действий.
5. Блок преимуществ или включенных услуг.
6. Нижняя навигация.

Hero-блок может использовать:

- светло-голубой абстрактный фон;
- крупный заголовок в Lovelace / Playfair Display;
- короткий подзаголовок;
- primary-кнопку темно-синего цвета.

### 9.2. Карточки

Карточки — один из главных элементов интерфейса.

Правила:

- фон: `#FFFFFF`;
- обводка: `#B8DDFF` с низкой насыщенностью или opacity;
- радиус: 16-24 px;
- тень: отсутствует или очень мягкая;
- текст: `#14213E`;
- внутри карточки должно быть достаточно воздуха.

Для имиджевых карточек допустим светло-голубой фон или мягкий градиент.

### 9.3. Кнопки

#### Primary button

```text
Фон: #14213E
Текст: #FFFFFF
Радиус: 12-18 px
Шрифт: Tilda Sans / Inter SemiBold
```

Использовать для главного действия:

- «Заказать уборку»;
- «Выбрать тариф»;
- «Продолжить»;
- «Подтвердить заказ».

#### Secondary button

```text
Фон: #FFFFFF
Текст: #14213E
Обводка: #B8DDFF или #14213E с низкой opacity
Радиус: 12-18 px
```

Использовать для второстепенных действий:

- «Подробнее»;
- «Изменить»;
- «Посмотреть состав»;
- «Назад».

#### Disabled state

- фон: очень светлый серо-голубой;
- текст: темно-синий с низкой opacity;
- без резкого серого цвета.

### 9.4. Поля ввода

Правила:

- фон поля: белый;
- обводка: светло-голубая;
- активная обводка: темно-синяя;
- placeholder: темно-синий с низкой opacity;
- текст: темно-синий;
- радиус: 12-16 px.

Не использовать ярко-серые поля и тяжелые внутренние тени.

### 9.5. Нижняя навигация

Bottom navigation должна быть легкой и минималистичной.

Правила:

- фон: белый;
- активная иконка: темно-синяя;
- неактивная иконка: темно-синяя с низкой opacity;
- допустим светло-голубой pill/подложка для активного пункта;
- иконки — тонкие линейные, без заливки и лишних деталей.

### 9.6. Иконки

Стиль иконок:

- линейные;
- тонкие;
- спокойные;
- без мультяшности;
- цвет: `#14213E`;
- для подложек можно использовать `#B8DDFF`.

Не использовать разноцветные иконки, 3D-иконки, эмодзи и тяжелые пиктограммы.

## 10. Правила для ключевых экранов

### 10.1. Onboarding

Onboarding должен создавать ощущение легкости и доверия.

Использовать:

- голубой абстрактный фон;
- крупный эмоциональный заголовок;
- короткий текст;
- один главный CTA;
- минимум элементов.

Примеры тона:

```text
Нас манит чистота
Минимум действий, максимум результата
Уборка без лишних забот
Чистота — в пару касаний
```

### 10.2. Каталог услуг

Экран услуг должен быть понятным и структурным.

Правила:

- не перегружать карточки;
- показывать отличие тарифов коротко;
- использовать белые карточки с тонкой голубой обводкой;
- для выбранного тарифа можно использовать светло-голубую подложку;
- primary-кнопка всегда темно-синяя.

Возможные названия тарифов из айдентики:

```text
Базовый минимум
Генеральская
Роскошный максимум
```

### 10.3. Детальная страница услуги

Для длинных списков работ использовать белый фон.

Правила:

- список должен легко сканироваться;
- разделы отделять заголовками;
- использовать тонкие divider-линии или мягкие голубые подложки;
- не размещать длинный текст поверх декоративного фона.

### 10.4. Оформление заказа

Оформление заказа должно быть максимально простым.

Правила:

- белый фон;
- четкая пошаговая структура;
- минимум визуального шума;
- важные действия — темно-синие кнопки;
- вспомогательные блоки — в светло-голубых карточках;
- итоговая стоимость должна быть заметной, но не агрессивной.

### 10.5. Профиль и настройки

Профиль должен быть спокойным и функциональным.

Правила:

- белый фон;
- простые строки настроек;
- тонкие разделители;
- минимум декоративных элементов;
- акцент только на важных действиях.

### 10.6. Empty state

Empty state может быть более декоративным.

Использовать:

- светло-голубую иллюстрацию;
- символ логотипа как фон;
- короткий дружелюбный текст;
- одну кнопку действия.

Пример:

```text
Пока здесь чисто и пусто
Закажите первую уборку — мы все подготовим
```

## 11. Тон коммуникации

Тон бренда:

- спокойный;
- уверенный;
- чистый;
- понятный;
- заботливый;
- без давления;
- без дешевого рекламного пафоса.

Подходящие формулировки:

```text
Минимум действий, максимум результата
Уборка без лишних забот
Чистота в пару касаний
Мы уже включили главное
Больше опций — меньше хлопот
```

Избегать:

```text
Срочно!
Только сегодня!
Лучшие цены!
Супер-скидка!
Шок-предложение!
```

## 12. Motion и микровзаимодействия

Анимации должны быть мягкими и незаметными.

Разрешено:

- плавное появление;
- легкий fade;
- мягкий slide;
- плавное раскрытие карточки;
- аккуратное изменение opacity;
- легкое масштабирование до 1.02 для выбранных элементов.

Не использовать:

- резкие прыжки;
- cartoon bounce;
- агрессивные shake-анимации;
- перегруженные loader-анимации;
- слишком быстрые переходы.

## 13. Accessibility и UX-ограничения

ИИ-агент обязан проверять удобство интерфейса.

Правила:

- не размещать мелкий текст на голубом декоративном фоне;
- основной текст должен быть темно-синим на белом фоне;
- кликабельные элементы не меньше 44 px по высоте;
- главный CTA должен быть видимым без поиска;
- не использовать только цвет для обозначения статуса;
- текст должен быть достаточно крупным для мобильного экрана;
- длинные списки должны быть разбиты на секции;
- не перегружать один экран большим количеством вариантов.

## 14. Что ИИ-агент должен делать перед генерацией экрана

Перед созданием любого экрана агент должен ответить себе на вопросы:

1. Этот экран выглядит чисто, спокойно и воздушно?
2. Есть ли достаточно белого пространства?
3. Используются ли только брендовые цвета?
4. Не мешает ли декоративный фон чтению?
5. Главный CTA легко найти?
6. Заголовки не выглядят слишком тяжелыми?
7. Карточки и кнопки соответствуют премиальному минимализму?
8. Визуал не похож на обычный дешевый клининг-сервис?
9. Экран удобно использовать одной рукой?
10. Вся композиция работает на ощущение чистоты и доверия?

Если ответ хотя бы на один вопрос отрицательный — экран нужно упростить.

## 15. Жесткие запреты

ИИ-агенту запрещено:

- добавлять новые брендовые цвета без необходимости;
- использовать черный как основной цвет вместо `#14213E`;
- делать интерфейс ярким, кислотным или мультяшным;
- использовать тяжелые тени и грубые градиенты;
- размещать длинный текст на сложном декоративном фоне;
- использовать слишком много фотографий на одном экране;
- делать кнопки разными по стилю без причины;
- искажать логотип;
- использовать декоративный шрифт для всего интерфейса;
- делать интерфейс похожим на медицинское, банковское или промышленное приложение;
- перегружать экран иконками и бейджами.

## 17. Пример системного промпта для ИИ-агента

```text
Ты создаешь интерфейс мобильного приложения «Клиномания».
Соблюдай айдентику бренда: белый фон, светло-голубые акценты #B8DDFF, темно-синий текст #14213E, много воздуха, мягкие формы, премиальный минимализм.
Для заголовков используй Lovelace Regular или Playfair Display, для интерфейсного текста — Tilda Sans, Inter или Arial.
Не используй яркие цвета, тяжелые тени, мультяшные иллюстрации и перегруженные экраны.
Декоративные голубые фоны применяй только там, где они не мешают чтению: onboarding, hero-блоки, промо-карточки, empty states.
Основные формы, списки, оформление заказа и настройки делай на белом фоне.
Главные кнопки — темно-синие с белым текстом. Карточки — белые, с мягкими скруглениями и тонкой голубой обводкой.
Каждый экран должен выглядеть чистым, спокойным, дорогим и понятным.
```

## 18. Критерий хорошего результата

Хороший экран «Клиномании» выглядит так, будто пользователь уже чувствует чистоту до заказа услуги: белый воздух, мягкий голубой свет, аккуратные карточки, спокойная типографика и понятное действие.

Плохой экран выглядит как обычное перегруженное приложение услуг: много цветов, много иконок, случайные фото, тяжелые кнопки, мало воздуха и нет ощущения премиальной чистоты.
